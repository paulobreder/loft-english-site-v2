# Site institucional — Loft English

Site estático (Astro + TypeScript) da Loft English, São Gabriel da Palha – ES.

- Rodar: `npm install` e `npm run dev`
- Gerar: `npm run build` (prévia, não indexável) ou `SITE_URL=https://seu-dominio npm run build` (produção)
- Dados de contato: **`src/config/site.ts`** (único arquivo)
- Status, testes e pendências: [`docs/STATUS.md`](docs/STATUS.md)
- Design system: [`docs/DESIGN-SYSTEM.md`](docs/DESIGN-SYSTEM.md)

Os materiais de briefing e pesquisa ficam fora deste repositório e não fazem parte da build publicada.

Prévia publicada (GitHub Pages, não indexada): ver a seção "About" do repositório.
