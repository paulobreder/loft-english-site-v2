# Fotos liberadas da escola

Esta pasta fica vazia até a autorização das fotografias.

Após confirmar os três itens de `mediaRelease.vidaNaLoft` em `src/config/site.ts`, copie para cá
(sem apagar os originais) os arquivos com estes nomes:

- `aula-coletiva.png`
- `selfie-turma.png`
- `atividade-lanche.png`

Podem ser .png, .jpg ou .webp. O site gera automaticamente as versões AVIF/WebP otimizadas.
